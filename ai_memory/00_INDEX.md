## Catatan Teknis Penting
- Production Readiness (Tahap 14): build type `preview` (`initWith(release)`, suffix `.preview`) WAJIB juga didefinisikan di setiap modul library (`core:common`, `core:viewmodel`, `domain`, `data`, `scripting:api`, `scripting:rhino`) dengan `initWith(getByName("release"))`; tanpa ini variant matching AGP gagal (app preview tak bisa konsumsi varian library). Signing: `signingConfigs.release` hanya terisi bila `keystore.properties` + keystore ada (`hasReleaseSigning`), jika tidak `release`/`preview` fallback ke `signingConfigs.debug` → build tak pernah gagal. ABI splits aktif: 4 APK per-ABI (`armeabi-v7a`/`arm64-v8a`/`x86`/`x86_64`) + `isUniversalApk = true`. ProGuard Wajib Rhino: `-dontwarn java.beans.**` + `-dontwarn org.mozilla.javascript.**` (R8 error tanpa ini karena `JavaToJSONConverters` mereferensikan `java.beans.*` yang tidak ada di Android). Firebase: plugin `google-services` & `firebase.crashlytics` dideklarasikan `apply false` di root, dan hanya di-apply + deps Firebase ditambahkan bila `app/google-services.json` ada.
- Full Script Canvas & Grid (Tahap 13): `RoCatUI` ekspansi `addGrid(columns, itemsJson, onClickFunction)`; `ScriptCanvasScreen`/`ScriptCanvasViewModel` memakai entry point `onLaunch()` (bukan `buildUI`), auto-run + session token, tombol Button mengumpulkan Input -> `Map<id,value>` via `invokeNamedFunction`; klik item Grid -> `invoke(script, fn, args = listOf(item.rawJsonPayload))` (payload JSON string yang di-`JSON.parse` lagi oleh JS); komponen `Grid`/`GridItem(title,imageUrl,rawJsonPayload)` di-parse dari JSON array via kotlinx-serialization; `GridView` = `LazyVerticalGrid` (`userScrollEnabled=false`) pakai tinggi terukur (tile 180dp) supaya bisa dimuat di dalam LazyColumn; `NavigationBar` hanya untuk Scripts/Playground (kanvas full-screen); `ScriptsScreen` menampilkan cover `script.icon` (`@icon`/`@iconURL`) via Coil `AsyncImage`, fallback ikon Extension. Contoh `CANVAS_EXAMPLE_SCRIPT` = demo Search->Grid->Detail ('Manga Scraper Mock') tersedia via tombol 'Canvas demo' di Import.
- Script-Driven UI (Tahap 12 revisi): global `RoCatUI` tersedia di Rhino scope saat `environment.ui != null` (`ScriptUiBridge`: `addInput(id,hint)`, `addButton(label,functionName)`, `thumbnailPreview(url)`, `videoPreview(url)`, `clear()`, `log(text)`); `buildUI()` dipanggil Kotlin otomatis; tombol mengumpulkan semua nilai `ScriptUIComponent.Input` → `Map<id,value>` → `ScriptEngine.invokeNamedFunction()` mengubahnya jadi 1 argumen objek JS (`inputs.video_url`); return `undefined` diflatkan jadi `""`; UI update dimarshal `Dispatchers.Main` + `uiSession` token membuang render lama. Kontrak lama `{"media_type":"image"/"video","media_url":...}` masih dirender di `CopyableResultCard`.
- Media Renderer & Smart Inputs (Tahap 12 awal): argumen Playground value-only (`testArgs: List<String>`, default `List(1){""}`, tombol "+ Add Input"); regex Public vs Private = `function\s+(?!_)([a-zA-Z$][\w$]*)\s*\(`; Coil 3.0.4 (`coil-compose` + `coil-network-okhttp`). — Digantikan oleh Playground script-driven (testArgs dihapus).
- Playground hotfix (Tahap 11.5): tidak ada lagi card "Run main"/Target URL; `testFunctionSuggestions` diisi otomatis dari `extractFunctionNames(script.source)` (Regex `function\s+([a-zA-Z_$][\w$]*)\s*\(`) saat skrip dipilih/dimuat, `testFunction` default = fungsi pertama; `testArgs` default `emptyList()` → input hanya muncul setelah tombol "+ Add Input"; display & copy di `CopyableResultCard` memakai `ResultFormatter.prettyJson` (JSON pretty-print, non-JSON fallback raw) dan teks dibungkus `SelectionContainer` agar bisa diseleksi. 
- Playground dinamis (Tahap 11): `testArgs: List<TestArg(label,value)>` (baris input Key+Value bisa ditambah/dihapus, nilai blank dilewati saat pemanggilan); `testFunction` editable + suggestion (`search/detail/main`) → `ExecuteScript.invoke(script, fn, args)`; hasil bisa disalin via `CopyableResultCard` (Copy JSON = pretty-print `Json { prettyPrint=true }` fallback ke teks asli jika bukan JSON; Copy Text = raw) dengan `LocalClipboardManager` + `Toast`.
- Stealth network (Tahap 10): `AndroidCookieJar` = OkHttp `CookieJar` ber-basis `WebView CookieManager` → cookie OkHttp & WebView identik (persisten, sync + `flush()`); `CloudflareInterceptor` bypass CF challenge via headless WebView di main thread (`Handler(mainLooper)`, latch 30s, cek cookie `cf_clearance` baru, retry, lalu `destroy()` WebView); `StealthHeadersInterceptor` default header Chromium (`Sec-CH-UA*`, `Sec-Fetch-*`, `Accept-Language`) hanya bila header belum ada; `NetworkHelper(context)` pasang cookie jar + UA + stealth headers + CF interceptor, `newScriptClient()` mewarisi semua.
- Network (Tahap 7): `network_security_config.xml` aktif (cleartext + trust system/user); `NetworkHelper.DEFAULT_USER_AGENT` = `Chrome/141.0.0.0`; ConnectionSpec `MODERN_TLS/COMPATIBLE_TLS/CLEARTEXT`; `ScriptSourceFetcher.normalizeUrl()` otomatis inject `https://` & rewrite GitHub blob→raw; `WebViewUtil.setDefaultSettings()` utk engine fallback.
- Rhino 1.7.15: support `let/const`, arrow fn, template literal, Promise, generator; TIDAK support `async/await`, spread, optional-chaining, class. Script sample harus ditulis sync (`fetch()` mengembalikan objek Response sync dengan `.text()`/`.json()`).
- Rhino di Android WAJIB mode interpretasi (`optimizationLevel = -1` di `ScriptContextFactory.makeContext()`): tanpa ini Rhino mengompilasi JS ke `.class` Java standar yang tidak bisa dimuat classloader Android → error "can't load this type of class file". Efek samping: bilangan bulat dikembalikan sbg `Double` (`42.0`) → dinormalisasi via `valueToString()`.
- `fetch()` bridge: sync, melewati `scriptFetch` (OkHttp client app), balikkan `{status,statusText,ok,url,body,headers,error,text(),json()}`. Arg URL harus dikonversi `Context.toString` (Rhino `ConsString` bukan `java.lang.String`).
- `RoCatDOM` (Tahap 8): global DOM bridge berbasis Jsoup; `parse/select/selectText/selectAttr/selectHtml/has`; elemen wrapper punya `text,html,innerHtml,attrs,attr(),has(),contains(),find(),textOf(),attrOf(),textsOf(),nextElement()` — semua balik nilai JS native.
- `ScriptEngine.invokeFunction()` (Tahap 8): evaluasi source → panggil fungsi bernama (`search`/`detail`) → hasil `NativeJSON.stringify`. Dipakai Playground "Test Execution" (Run Search/Run Detail).
- Watchdog: `ScriptContextFactory` + instruction budget 10M; timeout network di `NetworkHelper.newScriptClient()`.
- Parser metadata: blok `==UserScript==` atau fallback `// @tag`; tag `@name/@version/@description/@author/@match/@include/@icon(/iconURL)`.
