public class Watchdog {
    static class F extends ContextFactory {
        int budget;
        F(int b){ this.budget = b; }
        protected Context makeContext() {
            Context cx = new Context(this) {
                long total = 0;
                protected void observeInstructionCount(int count) {
                    total += count;
                    if (total > budget) {
                        throw new EvaluatorException("Script execution timed out");
                    }
                }
            };
            cx.setInstructionObserverThreshold(10000);
            return cx;
        }
    }

## Tahap 2 — Infrastruktur Script
- **Metadata Parser** (`domain/script/ScriptMetadataParser.kt` + `ScriptMetadata`): parse blok `==UserScript==` (fallback ke tag lepas), mendukung `@name`, `@version`, `@description` (multi-line), `@author`, `@match`/`@include`, `@icon`/`@iconURL`.
- **Fetch bridge (`RhinoScriptEngine`)** ditulis ulang: semua request lewat `OkHttpClient` app yang sama via helper `scriptFetch` (status/header asli, tidak throw). Bridge mengembalikan objek Response sync `{status, ok, headers, body, error, text(), json()}` dan menerima `fetch(url, {method, headers, body})` maupun positional. Ada watchdog `ScriptContextFactory` (instruction budget 10M) agar infinite loop & request gantung tidak crash (timeout 30s di script client).
- **Storage/CRUD**: `ScriptRepositoryImpl` (file JSON) + interactor `ImportScript`, `DeleteScript`, `SetScriptEnabled`, `UpsertScript` (auto-parse metadata), `ScriptSourceFetcher` (download via URL, rewrite GitHub blob).
