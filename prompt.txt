# Project: Separate Manage Sources from Filter/Sort Dialog and Fix Recommendation Logic

## Context
In the previous iteration, we combined "Manage Sources" into the `TabbedDialog` along with Filter and Sort options. However, this caused a bug where **no recommendations are available/displayed** ("Gak ada rekomendasi yang tersedia"). 

In Mihon's architecture, managing sources and filtering/sorting recommendations serve different purposes. Including source selection inside the filter tabs interferes with the default source query/aggregation logic, causing the manga list to return empty.

## Tasks

### Step 1: Remove "Manage Sources" from Filter/Sort Dialog
Modify `eu.kanade.tachiyomi.ui.recommendations.RecommendationsTab` and `eu.kanade.presentation.recommendations.RecommendationsScreen`:
- Remove the "Manage Sources" tab from the `TabbedDialog` (or Filter/Sort sheet).
- The `TabbedDialog` should **only** contain:
  1. **Filter Tab** (for Genre filtering based on daily history recommendations).
  2. **Sort Tab** (for sorting options like Default, Latest Update, Random, Chapter Count).

### Step 2: Separate "Manage Sources" Entry Point
- Relocate "Manage Sources" to a dedicated action or menu item (e.g., inside an overflow menu / three-dot icon in the `TopAppBar`, or as a separate dedicated button/dialog), matching how standard Mihon tabs separate library settings from general source management.
- Ensure that modifying sources through this separate entry point correctly updates the saved preferences without breaking the active recommendation state.

### Step 3: Fix Empty Recommendation Bug
Review the manga aggregation and filtering logic in `RecommendationsTab`:
- Ensure that when the screen loads, recommendations are fetched by default from the user's active/enabled sources **without requiring the user to manually select sources inside the filter dialog**.
- Verify that `allManga` aggregation (`Combine First, Filter Later`) works correctly with the default selected sources so that the list is populated immediately on launch.

### Step 4: Testing & Clean Code (WAJIB)
1. Jalankan `./gradlew spotlessApply` untuk merapikan format kode.
2. Jalankan `./gradlew testDebugUnitTest` dan pastikan **BUILD SUCCESSFUL**.
3. Verifikasi bahwa daftar komik rekomendasi langsung muncul saat layar dibuka dan tidak lagi kosong (*no recommendations available*).
