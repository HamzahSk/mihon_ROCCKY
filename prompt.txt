Tolong tambahkan fitur **Manga Live Translator (Tahap 1: OCR Detection)** pada komponen viewer/reader manga dengan ketentuan sebagai berikut:

## 1. UI & Penempatan Tombol
- **Tombol Action Baru**: Tambahkan tombol "Translate" di samping tombol *Favorite* / *Save* (misalnya di action bar atau toolbar reader).
- **Indikator Status**: 
  - Tombol memiliki state (Active/Inactive) dengan indikator visual yang jelas (misalnya perubahan warna ikon atau badge pulsing) saat fitur auto-translate sedang aktif.
  - Tambahkan animasi transisi halus saat status tombol berubah.

## 2. Logika Deteksi OCR (Auto-Detect saat Scroll Berhenti)
- **Scroll Detection**: Buat listener/observer pada scroll state di halaman baca manga.
- **Debounce / Interval**: Jalankan proses deteksi OCR hanya saat pengguna **berhenti melakukan scroll** selama **1,25 detik** (`debounce(1250ms)`).
- **Proses OCR**:
  - Ambil *frame/image* yang saat ini sedang tampil di layar (*visible viewport*).
  - Gunakan SDK OCR (seperti Google ML Kit Text Recognition) untuk mendeteksi area dan teks pada panel komik.
  - Buat overlay transparan di atas gambar komik untuk menggambarkan/menuliskan ulang teks (*text overlay*) tepat di lokasi bounding box teks yang terdeteksi.

## 3. Arsitektur & Persiapan Integrasi (Tahap 1)
- **Persiapan Modul API Translator**:
  - Buat abstraksi / Interface khusus untuk service pemroses teks (misal: `MangaTranslatorEngine`).
  - Untuk tahap ini, hasil keluaran dari OCR cukup dituliskan kembali (mock/raw text) pada overlay tanpa diproses ke API penerjemah eksternal terlebih dahulu.
  - Pastikan struktur data fleksibel agar siap diintegrasikan dengan API Translator (seperti Google Translate / DeepL API) pada tahap selanjutnya.

## 4. Performa & Best Practice (Jetpack Compose / Android)
- **Resource Management**: Proses OCR harus berjalan secara *asynchronous* (menggunakan Coroutines / Background Thread) agar UI tidak *lag* atau *stuttering* saat pengguna membaca.
- **Batal Otomatis (Cancellation)**: Jika pengguna mulai melakukan scroll kembali sebelum interval 1,25 detik selesai (atau saat OCR sedang berjalan), batalkan job OCR sebelumnya (*cancel ongoing job*).
- **Memory Optimization**: Bersihkan (*recycle/dispose*) cache gambar bitmap dan overlay saat halaman/chapter ditutup atau berpindah.

## 5. Catatan Penting
- **JANGAN** mengubah atau merusak fungsi tombol *Favorite*, *Save*, maupun fitur navigasi reader yang sudah ada.
- Pertahankan semua parameter dan *callback* event yang sudah berjalan pada layar reader.
- Pastikan ketersediaan izin (*permissions*) yang dibutuhkan jika mengambil *frame* dari layar.
