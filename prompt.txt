# Project: Refactor Data Aggregation, Genre Filtering, and Library-Style Pull-to-Refresh

## Context
We need to refine the `RecommendationsTab` in our Mihon/Tachiyomi fork to address data aggregation logic, filtering accuracy, and visual feedback during refresh actions. Currently, data is separated by source, genre filtering is not aligned with daily recommendation logic, and the Pull-to-Refresh behavior lacks proper loading animation and UI pattern consistency.

## Tasks

### Step 1: Implement Global Manga Aggregation & Reference Genre Recommendation Logic
Modify `RecommendationsViewModel` and its corresponding data repository/interactor:
- **Combine First, Filter Later:** Ensure manga data from all sources is merged/combined into a single unified list *before* any filtering or sorting logic is applied. Do not separate or group manga by individual sources.
- **Reference Logic from `BrowseSourceViewModel`:** Implement the daily data retrieval and genre-based recommendation logic by referencing how `applyRecommendationsFromHistory` is implemented in `app/src/main/java/eu/kanade/tachiyomi/ui/browse/source/browse/BrowseSourceViewModel.kt`. 
- **Daily Genre Filtering:** Ensure the aggregated manga list applies the daily genre filter accurately, adapting the recommendation approach from `applyRecommendationsFromHistory` to work across all combined sources globally.

### Step 2: Implement Library-Style Pull-to-Refresh & Animation
Modify `eu.kanade.presentation.recommendations.RecommendationsScreen`:
- **Match Library Implementation:** Align the Pull-to-Refresh logic, layout wrapper, and UI pattern directly with the implementation used in Mihon's `LibraryScreen` (or `LibraryContent`).
- **Add Loading Animation & State Binding:** Ensure the loading spinner/indicator is visible during refreshing actions and correctly bound to `viewModel.state.isRefreshing` / `viewModel.state.isLoading` so it dismisses smoothly when loading completes.
- **Nested Scrolling:** Ensure proper `nestedScroll` connection with the inner list/grid component so gesture handling and refresh animations behave seamlessly like in the Library screen.

### Step 3: Implement Mihon-Style Filter/Sorting UI
Modify `RecommendationsViewModel` and `RecommendationsScreen` to match Mihon's design system:
- Use the standard Mihon Filter/Sort Bottom Sheet (similar to the one used in the Library or Browse screens) to display genre filters and sorting options.
- Ensure the "Filter/Sort" icon in the `TopAppBar` correctly toggles this Bottom Sheet.

### Step 4: Testing & Clean Code (WAJIB)
1. Jalankan `./gradlew spotlessApply` untuk merapikan format kode.
2. Jalankan `./gradlew testDebugUnitTest` dan pastikan **BUILD SUCCESSFUL**.
3. Verifikasi bahwa perilaku dan animasi *pull-to-refresh* sudah identik dengan fitur *pull-to-refresh* di Library, serta data dari semua *source* sudah tergabung sebelum difilter dengan logika rekomendasi yang terinspirasi dari `applyRecommendationsFromHistory`.
