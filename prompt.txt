# Task: Fix Blank/Black Image Loading Bug in Reader

## 1. Context & Bug Description
Saat membaca komik di aplikasi Mihon, beberapa halaman/gambar mengalami bug berupa tampilan **blank hitam**. 
- Gambar yang blank masih bisa di-scroll seperti biasa.
- Halaman/gambar setelahnya terkadang load secara normal.
- Setelah diverifikasi ke web/source aslinya, gambar tersebut **ada dan tidak rusak** (bukan masalah pada *source scraper*).
- Bug ini hanya terjadi pada beberapa gambar tertentu (diduga berkaitan dengan kegagalan *image decoding*, *caching*, format gambar tertentu seperti WebP/Progressive JPEG, atau *out-of-memory* pada gambar beresolusi tinggi/panjang).

## 2. Objective
Perbaiki bug pada sistem *image loading* / *reader* agar semua gambar dapat di-decode dan ditampilkan dengan benar tanpa memunculkan frame hitam/blank.

## 3. Investigation & Action Steps

### Step 1: Analyze Reader & Image Loader
- Periksa komponen *image loader* yang digunakan pada reader (misalnya Coil, Glide, atau custom decoder Mihon).
- Evaluasi penanganan *error callback*, *fallback*, dan *cache miss* saat gambar gagal di-decode.

### Step 2: Fix Decoding & Memory Issues
- Pastikan aplikasi dapat menangani berbagai format gambar (JPEG, PNG, WebP, GIF, AVIF) dengan benar.
- Jika gambar hitam disebabkan oleh *Out Of Memory* (OOM) pada bitmap beresolusi sangat tinggi/panjang (sering terjadi pada *manhwa/webtoon*), tambahkan mekanisme *downsampling*, *subsampling*, atau *retry* yang sesuai.
- Jangan sampai perbaikan ini merusak performa *smooth scrolling* pada Reader.

### Step 3: Implement Retry / Error Recovery
- Jika proses render gambar sempat gagal sementara, pastikan ada mekanisme *auto-retry* atau *reload* siluman sehingga gambar tidak statis menjadi hitam permanen.

### Step 4: Testing & Clean Code (WAJIB)
1. Jalankan `./gradlew spotlessApply` untuk merapikan format kode.
2. Jalankan `./gradlew testDebugUnitTest` dan pastikan **BUILD SUCCESSFUL**.
3. Verifikasi bahwa daftar komik rekomendasi langsung muncul saat layar dibuka dan tidak lagi kosong (*no recommendations available*).
