# Prompt: Perbaikan Fitur Auto Translator & Integrasi Izin Screen Capture (MediaProjection)

## Context & Status
- **Status Sebelumnya:** Issue `NullPointerException` pada inisialisasi `OcrEngineImpl.kt` saat tombol Translate diklik sudah berhasil diperbaiki (FIXED).
- **Kebutuhan Saat Ini:** Perlu dilakukan penyesuaian ulang pada alur kerja fitur Auto Translator agar sebelum melakukan OCR/Translasi, aplikasi memicu dialog izin perekaman/mentransmisikan layar (*MediaProjection API*) dari sistem Android saat tombol Translate/Auto Translate diklik.

---

## Tugas & Spesifikasi Perbaikan

Tolong berikan perbaikan kode untuk `ReaderActivity.kt` dan komponen terkait dengan ketentuan berikut:

1. **Integrasi `MediaProjectionManager` (Screen Capture Permission):**
   - Saat tombol Translate diklik dari UI Reader (`ReaderActivity$AppBars`), aplikasi tidak boleh langsung menjalankan proses OCR/Capture secara silent.
   - Panggil `MediaProjectionManager.createScreenCaptureIntent()` untuk memicu pop-up dialog sistem standar: *"Izinkan [Nama Aplikasi] merekam atau mentransmisikan layar?"*.

2. **Handling Permission Result (`ActivityResultLauncher`):**
   - Gunakan `registerForActivityResult` dengan contract `ActivityResultContracts.StartActivityForResult()` di level `Activity` (`ReaderActivity`).
   - **Jika Pengguna Memilih "Mulai Sekarang" (`RESULT_OK`):** Ambil `Intent` data hasil permission, jalankan service/proses `MediaProjection` untuk mengambil screenshot layar, lalu teruskan gambar tersebut ke `OcrEngineImpl` untuk diproses.
   - **Jika Pengguna Memilih "Batal":** Berikan respons *graceful degradation* (misalnya tampilkan Toast atau Snackbar bahwa izin perekaman layar diperlukan untuk menjalankan fitur auto-translate).

3. **Arsitektur & State Management:**
   - Kelola state izin dan instansiasi OCR melalui `ViewModel` / Lifecycle-aware Scope agar tidak terjadi *memory leak* atau instansiasi ulang yang berlebihan di Compose Layer (`ReaderActivity$AppBars`).

4. **Output yang Diharapkan:**
   - Berikan perbaikan kode lengkap pada `ReaderActivity.kt` (termasuk pendaftaran `ActivityResultLauncher` dan pemicuan intent).
   - Berikan contoh penyesuaian pada `ViewModel` / Service pendukung untuk menangani data `MediaProjection` hasil dari dialog izin tersebut.
