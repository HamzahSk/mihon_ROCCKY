# Project: Refactor Data Aggregation, Genre Filtering, and Pull-to-Refresh Animation

## Context
We need to refine the `RecommendationsTab` in our Mihon/Tachiyomi fork to address data aggregation logic, filtering accuracy, and visual feedback during refresh actions. Currently, the data is separated by source, the genre filter is not aligned with the daily recommendation logic, and the Pull-to-Refresh feature lacks loading animation, making the UI appear unresponsive.

## Tasks

### Step 1: Implement Global Manga Aggregation Before Filtering
Modify `RecommendationsViewModel` and its corresponding data repository/interactor:
- **Combine First, Filter Later:** Ensure manga data from all sources is merged/combined into a single unified list *before* any filtering or sorting logic is applied. Do not separate or group manga by individual sources.
- **Daily Genre Filtering:** Implement daily data retrieval based on genre filters, similar to the recommendation logic used in `BrowseSourceScreen`. The aggregated list should be filtered accurately according to the selected genre for the day.

### Step 2: Fix Pull-to-Refresh Loading Animation
Modify `eu.kanade.presentation.recommendations.RecommendationsScreen`:
- **Add Loading Indicator:** The pull-to-refresh functionality currently works logically but lacks visual feedback. Integrate a Material 3 `PullToRefresh` loading spinner/indicator (e.g., using `PullRefreshIndicator` or `PullToRefreshBox` depending on Compose version).
- **State Management:** Ensure the animation indicator is strictly bound to `viewModel.state.isRefreshing` or `viewModel.state.isLoading`, so the spinner is visible while data is fetching and dismisses smoothly once loading completes.
- **Nested Scrolling:** Ensure the proper `nestedScroll` connection is applied to the inner `LazyVerticalGrid` or `LazyColumn` so the pull gesture triggers the animation without layout stuttering.

### Step 3: Implement Mihon-Style Filter/Sorting UI
Modify `RecommendationsViewModel` and `RecommendationsScreen` to match Mihon's design system:
- Use the standard Mihon Filter/Sort Bottom Sheet (similar to the one used in the Library or Browse screens) to display genre filters and sorting options.
- Ensure the "Filter/Sort" icon in the `TopAppBar` correctly toggles this Bottom Sheet.

### Step 4: Testing & Clean Code (WAJIB)
1. Jalankan `./gradlew spotlessApply` untuk merapikan format kode.
2. Jalankan `./gradlew testDebugUnitTest` dan pastikan **BUILD SUCCESSFUL**.
3. Verifikasi bahwa animasi *loading* muncul saat *pull-to-refresh* dan data dari semua *source* sudah tergabung dengan benar sebelum difilter.
