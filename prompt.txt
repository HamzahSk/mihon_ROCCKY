Tolong lakukan analisis dan perbaikan (bug fixing) pada fitur OCR Reader yang mengalami crash saat tombol Translate diklik.

## 1. Detail Error & Context Crash
Aplikasi mengalami crash `NullPointerException` pada file `OcrEngineImpl.kt` saat diinstansiasi dari tombol UI Compose (`ReaderActivity$AppBars`):

- **Error Stacktrace:**
  `java.lang.NullPointerException: Attempt to read from field 'com.google.mlkit.vision.text.internal.zzp com.google.mlkit.vision.text.internal.zzo.zza' on a null object reference`
  `at eu.kanade.tachiyomi.ui.reader.translate.OcrEngineImpl.<init>(OcrEngineImpl.kt)`

## 2. Tugas & Analisis
Tolong periksa file `OcrEngineImpl.kt` dan komponen pembilangnya di `ReaderActivity`:

1. **Inisialisasi `TextRecognizer`**:
   - Pastikan inisialisasi ML Kit `TextRecognition.getClient(...)` **tidak dilakukan secara synchronous** langsung di dalam constructor utama `OcrEngineImpl`.
   - Gunakan pendekatan `by lazy` atau bungkus dengan safe initialization/try-catch agar tidak melempar NullPointerException jika Context atau ML Kit Engine belum siap.

2. **Pengelolaan Context**:
   - Pastikan `Context` yang di-pass ke `OcrEngineImpl` adalah `ApplicationContext` atau `Activity Context` yang valid dan tidak bernilai `null`.

3. **Inisialisasi di Compose Layer (`ReaderActivity$AppBars`)**:
   - Jangan membuat instansi baru `OcrEngineImpl` langsung di dalam event `onClick` Compose secara langsung tanpa `CoroutineScope` / Dependency Injection (Injekt).
   - Gunakan `remember` atau kelola `OcrEngineImpl` di dalam `ViewModel` / Lifecycle-aware Scope agar instansinya aman dan tidak terus-menerus dibuat ulang setiap tombol diklik.

4. **Error Handling**:
   - Tambahkan blok `runCatching` / `try-catch` saat memanggil method OCR agar jika library ML Kit gagal memuat model, aplikasi tidak langsung crash total (*graceful degradation* dengan fallback notification/toast).

Tolong berikan perbaikan kode lengkap untuk file `OcrEngineImpl.kt` dan contoh pemanggilannya di UI Reader (`ReaderActivity`).
