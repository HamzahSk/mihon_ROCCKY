**Tugas:**
Bertindaklah sebagai Senior Android Developer. Tolong buatkan panduan dan implementasi kode lengkap untuk menambahkan fitur **Custom Font** di dalam aplikasi Android saya.

**Konteks & Lokasi Fitur:**
Fitur ini berada di menu **Pengaturan Tampilan** (satu halaman dengan pengaturan Tema, Format Tanggal, dll).

**Spesifikasi Fitur:**
1. **Upload Font:** User bisa memilih dan mengunggah (upload) file font kustom mereka sendiri (format `.ttf` atau `.otf`) menggunakan File Picker.
2. **Simpan & Terapkan:** Font yang diupload disimpan dengan aman (misalnya di internal storage) dan diterapkan secara global ke seluruh aplikasi.
3. **Smart Font Adjustment (Sangat Penting):** Karena ini font dari luar, seringkali metriknya tidak standar (contoh: hurufnya jauh lebih besar dari ukuran default, *line-height* berantakan/terpotong, atau *letter-spacing* terlalu renggang). Tolong buatkan *logic* untuk **menyesuaikan atau menormalisasi font tersebut**. Gunakan pendekatan seperti membaca `FontMetrics` untuk menyesuaikan *line-height* dan *baseline*, atau berikan fungsi *scaler* proporsional agar tampilannya tetap rapi dan tidak merusak layout UI aplikasi.

Tolong berikan solusi kodenya (bisa menggunakan Jetpack Compose atau XML, sesuaikan dengan best practice) dengan struktur langkah berikut:

**LANGKAH 1: UI Pengaturan Tampilan & File Picker**
Berikan kode untuk UI menu pengaturan dan *intent/launcher* untuk memilih file font.

**LANGKAH 2: Logic Penerapan Font & Smart Adjustment**
Berikan kode cara menyimpan file secara lokal, mendaftarkan font tersebut ke sistem *Typography* aplikasi, serta algoritma/perhitungan untuk menormalisasi ukuran dan jarak font.

**LANGKAH 3: Testing & Clean Code (WAJIB)**
1. Jalankan `./gradlew spotlessApply` untuk merapikan format kode.
2. Jalankan `./gradlew testDebugUnitTest` dan pastikan **BUILD SUCCESSFUL**.
